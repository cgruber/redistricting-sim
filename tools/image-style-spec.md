# Image Generation Style Spec

This file sets the baseline style for AI-generated reference images used in the Past the Post game.

## Visual Style

Fallout / Vault Boy inspired cartoon illustration. Clean 2D cartoon character. Bold black outlines.
Flat cel-shading with a single highlight tone per color region. No gradients. No photorealism.
Retro 1950s American cartoon aesthetic. Self-contained sticker-like quality with transparent background.

## Character Proportions

Waist-up portrait unless otherwise specified. Large expressive head relative to body.
Exaggerated cartoon proportions: oversized head, big round eyes, small simple nose.
Friendly and approachable but with clear personality.

## Color and Rendering

Bold black outlines (2-3px weight). Flat color fills. Simple cel-shading: one base tone,
one slightly darker shadow tone. Maximum 4-5 colors per character. Vivid, saturated palette.
White highlights on face and clothing. Transparent or plain background.

## Expression and Pose

Clear, readable expressions. Large eyes convey emotion. Pose must be instantly legible as
a silhouette. Hands and gesture should be the focus of the pose state.
